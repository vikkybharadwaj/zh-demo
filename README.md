# zh-demo
zh-demo


Interactive prototype: **Bulk on AUTH** (moving crypto from Coinbase into Northwind).

Source of truth: the Claude artifact at https://claude.ai/artifact/CSBMJkZrRh5on8XD3GcVYF

## Run

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

Jump to a scenario with `#star-N` (1, 3, 5, 7, 10, 11), e.g. `http://localhost:8000/#star-10`.
